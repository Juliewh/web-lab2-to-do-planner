# To-Do List

## О проекте

Веб приложение для планирования личных задач. Для каждой задачи указываются название и срок выполнения. Список можно менять и упорядочивать. Состояние задач сохраняется в браузере.

## Возможности

- Добавление задачи с названием и датой выполнения;
- Редактирование названия и даты, а также удаление задачи;
- Переключение статуса выполнения с визуальным оформлением завершённых задач;
- Поиск по части названия без учёта регистра;
- Фильтрация списка: все, активные или выполненные задачи;
- Сортировка по дате: сначала ближайшие или сначала поздние сроки;
- Ручное изменение порядка с помощью drag-and-drop. Перетаскивание доступно в режиме ```Как добавлены```, когда поиск пустой и выбран фильтр ```Все задачи```.
- Автоматическое сохранение задач в ```localStorage``` и восстановление списка при следующем открытии приложения в том же браузере.

## Структура проекта

- ```index.html``` - базовый каркас документа и подключение скрипта. Разметка приложения создаётся JavaScript.
- ```script.js``` - создание элементов страницы через DOM API и логика работы со списком задач.
- ```styles.css``` - оформление и адаптация страницы для узких и широких экранов.

## Технологии

HTML, CSS и чистый JavaScript с использованием DOM API. Сторонние библиотеки и фреймворки не используются.
